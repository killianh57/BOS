Comment ouvrir la formation

Fichier reçu par mail : formation_ecole-du-crocodile.html — 1 seul fichier, rien à installer, 2 minutes pour l'ouvrir correctement.

Ce qu'il faut savoir

Le fichier contient toute la formation (chapitres, photos, quiz). Il s'ouvre avec un navigateur internet : Chrome, Edge, Safari ou Firefox. Pas besoin de connexion une fois le fichier enregistré. Un seul réflexe : enregistrer le fichier, puis l'ouvrir — ne pas rester dans l'aperçu du mail (l'aperçu n'affiche qu'une partie et les quiz ne marchent pas).

Sur ordinateur (recommandé)

  1. Ouvre le mail et télécharge la pièce jointe (icône ou flèche « Télécharger »).
  2. Va dans ton dossier Téléchargements et double-clique sur le fichier.
  3. Il s'ouvre dans ton navigateur : clique sur les chapitres à gauche, fais les quiz.
S'il s'ouvre dans un éditeur de texte ou un programme bizarre : clic droit sur le fichier → Ouvrir avec → Google Chrome (ou Edge / Safari).

Sur Android

  1. Touche la pièce jointe dans le mail.
  2. Si le téléphone demande avec quoi l'ouvrir : choisis Chrome.
  3. Si ça ne fait que télécharger : ouvre l'app Fichiers → Téléchargements → touche le fichier → Chrome.

Sur iPhone / iPad

  1. Touche la pièce jointe : le document s'affiche en lecture seule (l'aperçu de l'iPhone ne lance pas les onglets ni les quiz).
  2. Pour la version complète avec les quiz : ouvre le fichier sur un ordinateur (ou un Android).

Bon à savoir

  1. Ta progression est mémorisée (chapitres lus ✓, records de quiz) sur l'appareil où tu ouvres le fichier. Garde donc le même fichier au même endroit et ouvre-le toujours avec le même navigateur.
  2. Tu peux refaire un quiz autant de fois que tu veux (bouton « Recommencer »).
  3. Le bouton Imprimer en haut à droite génère une version papier/PDF propre.
